# 片边 · Film Rebate

片边是一款在本机处理照片的 **Windows 胶片边框编辑器**。导入数码照片或扫描图，就能加上带片孔的 135 边框、无片孔的 120 边框，或拍立得相纸。可以逐张编辑，也可以批量制作一组风格统一的成片。

## 主要功能

| 功能 | 可以做什么 |
| --- | --- |
| 胶片边框 | 支持 135 全格、半格、XPan，以及 120 的 645、6×6、6×7 和 6×9。可搜索 Kodak、Fujifilm、乐凯、电影卷等胶卷，也可以自定义边印文字、颜色和光晕。 |
| 扫描效果 | 可调片孔底色、漏光强度和方向、胶片过期程度、边框圆角。日期印记可选样式并调整颜色和大小。 |
| 拍立得相纸 | 支持 Polaroid 和 instax 等相纸规格。可以换底色、图案或导入自己的边框图片。支持正反面并排和分别添加文字。 |
| 文字与多重曝光 | 可用内置中英文字体，直接拖动、旋转和拉伸文字。画笔可以从照片画到边框。每张照片可叠加最多 8 张图，逐层调节混合方式、强度、位置、角度和缩放。 |
| 拼图 | 最多放 40 张照片。多行胶片可选胶卷、起始帧号和行距。拍立得叠放可分别移动相纸和框内照片，也可设置背景比例、纯色或模糊照片背景。 |
| 批量处理 | 照片条支持多选、逐张修改和批量套用设置。导出可选当前、勾选或全部照片，多张可打包成 ZIP，也可暂停后继续。 |

## 快速上手

1. 启动「片边」，在主页点 **打开图片**，一次可导入多张照片。
2. 在照片条点击要编辑的照片，在右侧选择 **135、120 或拍立得**。双击预览里的框内照片，出现虚线后就可以拖动位置。点照片外退出调整。
3. 点击 **原图对比**，用左右并排或拖动分界线查看效果。要做多张拼图，点顶部的 **拼图**。
4. 点 **导出图片**，选择范围、文件格式和保存位置。软件会记住上次选择的导出格式。

## 文件格式与快捷键

- **导入**：支持 JPG、PNG、BMP、TIFF 和多种相机 RAW。RAW 能否读取取决于相机型号与文件编码。
- **导出**：支持 JPG、PNG、TIFF、BMP 和线性 DNG。导出的 DNG 保存的是已经渲染的成片。
- **Ctrl+A**：在照片条全选，再按一次取消全选。
- **Ctrl+Z** 撤回，**Ctrl+Y** 或 **Ctrl+Shift+Z** 重做。选中预览里的文字后，按 **Delete** 删除该段文字。

## 项目与隐私

照片在本机处理。主页的 **最近使用项** 可以恢复照片条、单张编辑设置和撤回历史。右键可移除单条列表记录，也可清空整个列表，这些操作不会删除电脑里的原图。自定义预设及常用保存路径会保留，拼图草稿在退出后清空。
